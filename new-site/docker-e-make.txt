GUIA RAPIDO: DOCKER, MAKE E CONTAINERS - NEW-SITE

Visao geral

Este projeto usa Docker Compose para subir tudo junto:
- front-site: front-end publico
- backoffice: painel administrativo
- backend: API em Go
- db: PostgreSQL

O arquivo principal de orquestracao fica em packages/docker-compose.yml.
O Makefile fica em packages/Makefile e so facilita os comandos do Docker Compose.

Onde rodar os comandos

Entre na pasta:

cd /home/henriquevieira/Area de trabalho/codes/semlab/semcomp/new-site/packages

Comandos do Make

Os comandos abaixo servem para nao precisar digitar docker compose o tempo todo.

1. make up
Sobe todos os servicos em modo background.
Use quando quiser iniciar o projeto sem rebuild.

2. make build
Sobe tudo e faz rebuild das imagens.
Use quando mudou codigo de front, backend ou Dockerfile.

3. make down
Derruba os containers do projeto.
Use quando quiser parar tudo sem apagar o volume do banco.

4. make restart
Derruba tudo e sobe novamente com rebuild.
Use quando quiser reiniciar o ambiente inteiro.

5. make logs
Mostra os logs de todos os servicos em tempo real.

6. make logs-front
Mostra os logs apenas do front-site.

7. make logs-backoffice
Mostra os logs apenas do backoffice.

8. make logs-backend
Mostra os logs apenas do backend.

9. make logs-db
Mostra os logs apenas do banco.

10. make bash-front
Abre um shell dentro do container do front-site.

11. make bash-backoffice
Abre um shell dentro do container do backoffice.

12. make bash-backend
Abre um shell dentro do container do backend.

13. make psql
Abre o cliente psql dentro do container do banco.

14. make ps
Mostra o estado dos containers do projeto semcomp.

Comandos equivalentes do Docker

Se quiser fazer sem Make, estes sao os comandos equivalentes:

Subir tudo:

docker compose -p semcomp --env-file ./backend/.env up -d

Subir tudo com rebuild:

docker compose -p semcomp --env-file ./backend/.env up -d --build

Derrubar tudo:

docker compose -p semcomp down

Derrubar tudo e apagar o volume do banco:

docker compose -p semcomp down -v

Ver logs:

docker compose -p semcomp logs -f

Ver status dos containers:

docker compose -p semcomp ps

Abrir shell no backend:

docker compose -p semcomp exec backend sh

Como rodar local fora do Docker

1. Backend
O backend e em Go, e o ponto de entrada e packages/backend/cmd/api/main.go.
Ele usa variaveis do arquivo packages/backend/.env.

Exemplo de subida local:

cd /home/henriquevieira/Area de trabalho/codes/semlab/semcomp/new-site/packages/backend
go run cmd/api/main.go

2. Front-site

cd /home/henriquevieira/Area de trabalho/codes/semlab/semcomp/new-site/packages/front-site
npm install
npm run dev

3. Backoffice

cd /home/henriquevieira/Area de trabalho/codes/semlab/semcomp/new-site/packages/front-backoffice
npm install
npm run dev

Observacao importante

Os frontends apontam para http://localhost:4000 quando VITE_DEBUG_MODE=true.
Entao, para funcionar localmente, o backend precisa estar rodando na porta 4000.

Como listar containers

Ver apenas os que estao rodando:

docker ps

Ver todos, inclusive parados:

docker ps -a

Ver os containers do projeto semcomp:

docker compose -p semcomp ps

Como matar, parar e remover containers

Parar um container:

docker stop NOME_OU_ID_DO_CONTAINER

Parar varios:

docker stop CONTAINER1 CONTAINER2

Remover um container parado:

docker rm NOME_OU_ID_DO_CONTAINER

Remover todos os containers parados:

docker container prune

Derrubar tudo do projeto semcomp:

docker compose -p semcomp down

Derrubar tudo e apagar o banco local do volume:

docker compose -p semcomp down -v

Dica pratica

Se o comando pedir permissao, voce pode usar sudo na frente, por exemplo:

sudo docker ps -a

Mas normalmente o ideal e configurar seu usuario para usar Docker sem sudo.
